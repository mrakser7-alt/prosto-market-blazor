# ПростоМаркет

Небольшой учебный сайт-каталог на C# и Blazor WebAssembly. Интерфейс публикуется через GitHub Pages, а пользователи и товары хранятся в Supabase PostgreSQL.

**Сайт:** https://mrakser7-alt.github.io/prosto-market-blazor/

## Возможности

- главная страница с простым слайдером;
- каталог с поиском и фильтрацией по категориям;
- регистрация, вход и личный кабинет;
- простая админка для добавления и удаления товаров;
- адаптивная вёрстка для телефона и компьютера;
- бесплатная публикация на GitHub Pages.

## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
dotnet restore
dotnet run
```

После запуска откройте адрес, который появится в терминале.

## База данных

SQL-схема находится в `supabase/migrations/20261026_initial.sql`. Она создаёт:

- таблицу `products` для общего каталога;
- таблицу `profiles`, связанную с Supabase Auth;
- автоматическое создание профиля после регистрации;
- Row Level Security: каталог читают все, изменяет только администратор.

Адрес проекта и публичный ключ задаются в `wwwroot/appsettings.json`. Секретный `service_role` ключ нельзя добавлять в браузерный проект.

## Важно

Если параметры Supabase не заданы, проект автоматически включает локальный демонстрационный режим. После настройки Supabase регистрация работает через Supabase Auth, а товары загружаются из PostgreSQL.

## Публикация

Готовая версия сайта размещается в ветке `gh-pages`. Основной исходный код находится в ветке `main`.

Фотографии взяты с [Unsplash](https://unsplash.com/) и сохранены локально в `wwwroot/images`, поэтому сайт не зависит от сторонней загрузки изображений.
