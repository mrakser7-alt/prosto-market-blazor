# ПростоМаркет

Небольшой учебный сайт-каталог на C# и Blazor WebAssembly. Проект сделан без лишних зависимостей и публикуется бесплатно через GitHub Pages.

## Возможности

- главная страница с простым слайдером;
- каталог с поиском и фильтрацией по категориям;
- регистрация, вход и личный кабинет;
- простая админка для добавления и удаления товаров;
- адаптивная вёрстка для телефона и компьютера;
- бесплатная публикация на GitHub Pages.

## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
dotnet restore
dotnet run
```

После запуска откройте адрес, который появится в терминале.

## Доступ в админку

- Почта: `admin@catalog.ru`
- Пароль: `admin123`

## Важно

Это демонстрационный учебный проект. Пользователи, сессия и товары хранятся в `localStorage` текущего браузера. Пароли хешируются, но такая схема не подходит для настоящего интернет-магазина: для продакшена нужны серверная авторизация и база данных.

## Публикация

Готовая версия сайта размещается в ветке `gh-pages`. Основной исходный код находится в ветке `main`.
